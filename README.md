# هدف برتر | سامانه آموزشی پایه هفتم تا نهم

این پروژه یک نسخه اولیه قابل اجرا از سامانه آموزشی «هدف برتر» است.

## امکانات پیاده‌سازی‌شده
- ثبت‌نام و ورود دانش‌آموز با رمز عبور هش‌شده
- پایه‌های هفتم، هشتم و نهم
- صفحه داشبورد دانش‌آموز
- فهرست درس‌ها و محتوای درس
- ساخت آزمون چهارگزینه‌ای و ثبت نتیجه
- محدودسازی درس/آزمون ویژه برای اشتراک طلایی
- پنل مدیریت برای مشاهده کاربران، درس‌ها، آزمون‌ها و نتایج
- افزودن و ویرایش و حذف درس
- ساخت آزمون و افزودن سؤال
- فعال‌سازی دستی اشتراک برای کاربران از پنل مدیر

## اجرای محلی
پیشنهاد می‌شود Python 3.11 یا جدیدتر نصب باشد.

```bash
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# لینوکس/مک:
source .venv/bin/activate

pip install -r requirements.txt
flask --app app init-db
```

ساخت مدیر اولیه (مقادیر نمونه را با اطلاعات خودت عوض کن):

**Windows PowerShell**
```powershell
$env:ADMIN_NAME="مدیر سایت"
$env:ADMIN_EMAIL="admin@example.com"
$env:ADMIN_PASSWORD="یک-رمز-عبور-قوی-و-منحصر-به-فرد"
flask --app app create-admin
flask --app app run
```

**Linux / macOS**
```bash
export ADMIN_NAME="مدیر سایت"
export ADMIN_EMAIL="admin@example.com"
export ADMIN_PASSWORD="یک-رمز-عبور-قوی-و-منحصر-به-فرد"
flask --app app create-admin
flask --app app run
```

سپس آدرس `http://127.0.0.1:5000` را باز کن.

## نکات مهم پیش از انتشار عمومی
این نسخه MVP و نقطه شروع توسعه است، نه نسخه آماده دریافت پول از کاربران.
- `SECRET_KEY` را در محیط اجرا با یک مقدار تصادفی و محرمانه تنظیم کن.
- از SQLite برای نمونه اولیه استفاده شده؛ برای میزبانی عمومی PostgreSQL پیشنهاد می‌شود.
- برای پرداخت واقعی باید درگاه معتبر متناسب با کشور و شرایط قانونی محل فعالیت انتخاب و به‌صورت امن سمت سرور متصل شود. اطلاعات کارت بانکی را هرگز در این سایت ذخیره نکن.
- قبل از انتشار، HTTPS، پشتیبان‌گیری، محدودیت تلاش ورود، ثبت رویدادهای مدیریتی، سیاست حریم خصوصی و شرایط استفاده اضافه و بررسی امنیتی انجام شود.
- برای استفاده دانش‌آموزان زیر ۱۸ سال، فرایند رضایت والدین/سرپرست و حداقل‌سازی داده‌های شخصی را متناسب با قوانین محل فعالیت طراحی کن.
- آزمون فعلی تستی است؛ زمان‌سنج سمت سرور، سؤال تشریحی، تصحیح تشریحی و ضدتقلب هنوز در نسخه بعدی توسعه داده می‌شوند.
